# ずぼら日記

毎日きちんと書かなくても大丈夫。気分・体調・充実度を1〜5のスライダーで記録し、書きたい日だけ「ひとこと」を残せる、ブラウザ内保存型の日記Webアプリです。

## 主な機能

### 記録
- 初期項目は「気分」「体調」「充実度」のスライダー3つと「ひとこと」の文章欄
- スライダーの初期値はすべて3
- 4つの初期項目は削除不可
- 項目の表示・非表示を選択して、必要なものだけ記録
- 独自項目を追加・編集・削除（スライダー型／文章記述型）
- スライダー型の項目は10色のグラフ線プリセットから色を選択
- 日付指定、記録の編集・削除、記録一覧と検索

### ふりかえり
- スライダー項目ごとの週間・月間・年間平均
- 直近30日間の数値推移を、丸みのある曲線で重ねて表示
- 月間カラーマップ。表示するスライダー項目を選択可能
- カラーマップの固定色：1=青、2=水色、3=緑、4=黄、5=ピンク
- 1日に複数回記録した場合は、その日の平均値をスタンプに反映

### 記録状況
- ホームの「YOUR LITTLE LOG」に、記録日が連続した最長日数を表示
- 同じ日に複数回記録しても1日として数え、日付が1日空くと連続日数をリセット

## 起動方法

`index.html` をブラウザで開くと利用できます。Google Fontsに接続できる場合は「Zen Maru Gothic」を読み込み、接続できない場合は端末の日本語フォントへフォールバックします。

## GitHub Pagesで公開

このZIPを解凍し、次のファイルとフォルダをリポジトリの直下にアップロードしてください。

```text
zubora-diary/
├── index.html
├── styles.css
├── app.js
├── README.md
```

GitHubリポジトリの **Settings → Pages** で、Build and deploymentを **Deploy from a branch**、Branchを **main**、Folderを **/(root)** にして保存します。

## データの保存と引き継ぎ

- 日記本文、項目、記録値はブラウザの `localStorage` に保存します。GitHubや外部サーバーへ日記本文を送信する処理はありません。
- 同じ端末・同じブラウザで開くと保存した内容を利用できます。別の端末やブラウザとは自動同期されません。
- ブラウザのサイトデータ削除で記録が消える場合があります。設定画面から定期的にJSONバックアップを保存してください。
- バックアップ読み込みは現在の保存内容を置き換えます。
- 旧版「ずぼら日記」の保存キー（`yohaku-diary-v1`）を引き継ぎ、以前の自由記述項目と日記内容を可能な範囲で新形式へ移行します。初期4項目は新たに追加されます。
