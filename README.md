# ずぼら日記

書きたい項目だけを選んで記録できる、日本語のシンプルな日記Webアプリです。

## 主な機能

- 日記を書くときに、登録済みの項目から必要なものだけ選択
- 項目の追加・名前の変更・削除
- 日付を指定して日記を保存
- 過去の日記の一覧表示、検索、編集、削除
- 日記と項目設定のJSONバックアップ・復元
- スマートフォン・PCに対応したレイアウト

## 起動方法

`index.html` をブラウザで開くと利用できます。Google Fontsの読み込み以外に外部ライブラリやサーバーは必要ありません。

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作成します（例：`zubora-diary`）。
2. このフォルダ内の `index.html`、`styles.css`、`app.js`、`README.md` をリポジトリの直下にアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment** の **Deploy from a branch** を選び、Branchを `main`、Folderを `/ (root)` にして保存します。
5. 公開処理が完了すると、同じPages画面にサイトURLが表示されます。

## データの保存について

日記本文と項目設定は、ブラウザの `localStorage` に保存されます。GitHubや外部サーバーへ日記本文を送信する処理はありません。

- 同じブラウザ・同じ端末で開くと、保存した日記を読み込めます。
- 別のブラウザや端末とは自動同期されません。
- ブラウザのサイトデータを削除すると日記も消える場合があります。
- 定期的に「項目設定」画面からJSONバックアップを書き出してください。
- バックアップを読み込むと、現在のデータがバックアップの内容に置き換わります。
